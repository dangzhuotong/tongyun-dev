# tongyun-dev PRD

## 目标

让本机多个开发项目能一键启停、看状态、跟日志；输出对人和 AI 都友好。项目不用手写配置：扫描一个目录就能登记。

## 非目标

- 断点调试、远程调试
- 依赖 IDEA Ultimate
- 改服务器 / 线上环境
- 多用户、云端托管

## 用户故事

1. 作为新用户，我第一次打开 App 看到「还没有项目」，点「扫描一个目录」选 `~/code`，勾选找到的项目加进来，不用写配置文件。
2. 作为开发者，我能 `start <id>`，等到端口通 / 探针成功；状态依次显示启动中、端口已通、就绪或失败（带原因和秒数）。
3. 作为开发者，我能随时 `stop <id>`，进程组停干净、端口释放。
4. 作为开发者 / Agent，我能 `status <id> --json` 看到：状态、pid、端口、探针码、日志路径、端口占用者。
5. 作为开发者 / Agent，我能 `logs <id> [--follow]` 读日志；App 里有实时日志面板，可搜索、高亮 ERROR。
6. 作为开发者，项目声明 `java = "8"` / `node = "20"` 时自动用对应版本，缺版本给出可读原因。
7. 作为开发者，我能在 App 里逐个项目修改设置（目录、启动 / 停止命令、端口、探针、版本、启用），写回配置时保留注释。
